One line that could have replaced an entire pointless meeting, entered in make.fun's "The Meeting That Should Have Been One Line" bounty. `main.py` (standard library only) writes the line to `/output/entry.txt`:

> The only decision we made today was to schedule another meeting about the decision we didn't make.

## Run it

```sh
python3 main.py
```
